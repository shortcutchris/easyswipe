# Swindoo name screening

Screening date: 19 August 2026

This document records a practical pre-launch search. It is not a legal opinion, does not prove that a name is available, and cannot replace a professional similarity search or advice from a trade-mark lawyer.

## Intended use

- Product: downloadable native macOS window-management software
- Core markets: Germany and the European Union, with worldwide open-source distribution
- Most relevant Nice classes: 9 (downloadable computer software) and 42 (software development and related services)

## Sources checked

- [TMview](https://www.tmdn.org/tmview/), coordinated by EUIPO, including participating national, EU and international offices
- [EUIPO search and availability guidance](https://www.euipo.europa.eu/en/search-ip)
- Apple software-catalogue search, GitHub repository search, general exact-name web search and software discovery
- Public registry status for the principal `swindoo` domains

## Exact-name result

An exact TMview search for `SWINDOO` returned no rows on 18 August 2026. No exact macOS app or exact GitHub repository representing a competing window manager was found in the searches performed.

The exact name has limited unrelated historical use. A Florida company named `SWINDOO LLC` was formed and dissolved in 2012. The result does not indicate a current software product, but it means the word has not been completely unused.

## Similar-name results

TMview's fuzzy search returned several visually or phonetically adjacent marks. The most relevant European result inspected was the active French combination mark `SWIMDOO`, registration 4288886, owned by ENGIE ENERGIE SERVICES. It covers classes including 42. Its listed services concern energy systems, aquatic and leisure facilities, engineering, technical audits and some computer programming; it is not presented as consumer window-management software.

Other returned results included `SWINGDOO` in Germany for classes 12, 20 and 28, `WINDOO` in Japan for class 12, and non-European `SAINDOO`, `SIINDOO`, `SWINDOW` and similar marks. Class numbers, territories, actual goods and services, visual presentation and commercial context all matter; a fuzzy result alone does not establish conflict.

The name is still pronounced almost identically to `Swindo`. Adding the second “o” improves the written identity and searchability, but it does not eliminate phonetic similarity to existing `Swindo`, `Swimdoo`, `Swindow`, `Windows` or related marks.

## Software-market and namespace result

- No exact `Swindoo` macOS app was found in the Apple software-catalogue search used for this screening.
- No exact GitHub repository name representing a competing window manager was found.
- No prominent exact-name downloadable software product was found in general web searches.
- `swindoo.com` is registered and resolves to an otherwise empty web-server directory. Its registry record shows registration on 5 February 2025 and expiry on 5 February 2027.
- `swindoo.app`, `swindoo.de`, `swindoo.eu`, `swindoo.dev`, `swindoo.io`, `swindoo.net` and `swindoo.org` appeared unregistered at the time of the check. Availability can change at any time and none of these names was reserved as part of the screening.

## Working assessment

`Swindoo` is a stronger working brand than `Swindo App`: it is short, visually more distinctive and retains the intended association with window gestures. The exact-name register and software-market results are favourable. The active `SWIMDOO` mark, other similar marks and the essentially unchanged pronunciation create residual similarity risk. The occupied `.com` domain also means the namespace is not completely clean.

The name is approved for implementation as a reversible product brand, but this screening must not be described as legal clearance.

Before a trade-mark application or substantial paid promotion:

1. Ask a German/EU trade-mark professional to interpret a similarity search for classes 9 and 42, including `SWIMDOO`, `SWINDO`, `SWINDOW`, `TWINDO`, `iwindo`, `WINDOWS` and phonetic variants.
2. Decide the exact goods-and-services wording before filing.
3. Reserve the preferred domain and important handles after the final legal review.
4. Keep the evidence and date of every follow-up search.

## Technical migration boundary

The public product presentation may say `Swindoo`. During the transition, the bundle identifier, executable, Swift module, Sparkle appcast URL, update public key, signing identity, preference keys and existing release repository remain unchanged. This preserves Accessibility permission and the signed update path for existing installations.
