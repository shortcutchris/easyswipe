# Swindoo 0.1.8

This visual-feedback update adds calm, optional motion to Swindoo's cursor-adjacent action HUD.

- Animate each preview and confirmation in the command direction without delaying or animating the window action itself.
- Compress the minimize symbol toward the Dock, expand the maximize symbol, and nudge half-screen confirmations left or right.
- Add a persistent “Show Animations” checkbox to the menu bar menu, enabled by default.
- Disable all HUD motion when the preference is off or macOS Reduce Motion is active, while preserving immediate visual feedback.
