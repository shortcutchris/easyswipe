# Swindoo 0.1.3

This transition release introduces the new Swindoo name while preserving the technical identity used by existing installations.

- Rename the visible app, menu, onboarding and gesture guide to Swindoo.
- Keep the existing bundle identifier, executable, preferences and Sparkle feed so Accessibility permission and in-place updates can continue.
- Update the English and German app copy for the new brand.
- Refresh the website, documentation, legal drafts and release presentation in English, German and French.
- Retain the window-compatibility improvements introduced in version 0.1.2.
