# Swindoo 0.1.9

This compatibility update extends two-finger window gestures across WhatsApp's split chat header.

- Recognize both top-edge Catalyst toolbar regions used by WhatsApp's chat list and active chat.
- Allow swipes directly over the active chat's contact header instead of only the left chat-list header.
- Keep call, video, menu, message, and composer controls outside the gesture surface.
- Preserve the strict top-edge geometry limit and existing behavior in native AppKit and SwiftUI toolbars.
