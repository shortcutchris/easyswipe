# EasySwipe 0.1.1

This maintenance update makes left- and right-half gestures more reliable across displays, display scaling modes, and applications with custom Accessibility behavior.

- Apply window size before and after positioning so macOS cannot retain a constrained height from the previous display.
- Work around `AXEnhancedUserInterface` while resizing affected applications.
- Verify that a window reached the complete requested frame and perform one bounded correction when needed.
- Preserve the full usable vertical screen height for left, right, and maximize gestures.
