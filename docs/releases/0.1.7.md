# Swindoo 0.1.7

This compatibility update extends Finder's measured-toolbar behavior to other macOS apps that expose the same native Accessibility structure.

- Recognize a real top-edge `AXToolbar` automatically across AppKit, SwiftUI, and compatible macOS windows.
- Start two-finger gestures over controls inside that measured toolbar, including Safari-style unified window controls.
- Keep ordinary clicks unchanged and retain the standard title-bar path without additional Accessibility traversal.
- Continue rejecting content toolbars, interactive content below the window chrome, dialogs, overlays, and windows without valid title-bar evidence.
