# EasySwipe 0.1.0

The first public EasySwipe release brings fast title-bar window gestures to macOS.

- Swipe left or right to fill the corresponding screen half.
- Swipe down to minimize the window.
- Swipe up to maximize within the usable desktop area without entering full screen.
- See immediate cursor-adjacent visual feedback while swiping.
- Use a trackpad, Magic Trackpad, or Apple Magic Mouse.
- Run entirely from the menu bar with English and German localization.
- Keep Accessibility permission across signed updates.
- Receive signed in-app updates through Sparkle.
