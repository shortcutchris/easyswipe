# Swindoo 0.1.6

This Finder compatibility update makes the complete unified toolbar available as a gesture start surface.

- Start two-finger gestures over Finder's view, grouping, share, tag, action, Dropbox, and search controls.
- Keep ordinary clicks on Finder toolbar controls unchanged.
- Restrict this exception to Finder's measured top toolbar; interactive content below it and controls in other apps remain excluded.
- Discover nested Finder toolbar accessibility elements with bounded traversal for compatibility across macOS window layouts.
