# Swindoo 0.1.4

This compatibility update adds reliable title-bar gestures for the current native WhatsApp app on macOS.

- Recognize WhatsApp's Catalyst contact-header surface as a valid gesture area.
- Keep call, video, menu and other interactive WhatsApp controls excluded from window gestures.
- Support the taller custom WhatsApp title bar while preserving the normal geometric title-bar boundary.
- Retain the existing bundle identifier, Accessibility identity and Sparkle update channel for seamless in-place updates.
