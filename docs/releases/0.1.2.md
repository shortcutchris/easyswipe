# EasySwipe 0.1.2

This compatibility update broadens title-bar gesture support across native and custom macOS windows, including Notion and other Electron- or Chromium-based apps.

- Recognize noninteractive web, toolbar, tab-group, list, and scroll containers as valid parts of a custom title bar.
- Walk deeper Accessibility hierarchies while still blocking real buttons, tabs, fields, selectable rows, and custom controls with activation actions.
- Ignore sheets, popovers, menus, tooltips, system dialogs, and borderless overlays that do not provide a dependable title bar.
- Support titled dialog and utility windows when they expose valid macOS title-bar semantics.
- Respect application-enforced minimum, maximum, and fixed window sizes while preserving successful position or size changes.
- Keep full-height left, right, and maximize placement across usable display areas.
