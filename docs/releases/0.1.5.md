# Swindoo 0.1.5

This compatibility update adds reliable gestures across Finder's unified title and toolbar surface.

- Use Finder's measured Accessibility toolbar frame instead of a fixed enlarged gesture zone.
- Accept the full noninteractive Finder toolbar surface while keeping search, view, share, action, and other controls excluded.
- Reject content toolbars and preserve the default title-bar boundary for every other app.
- Retain the existing bundle identifier, Accessibility identity, and Sparkle update channel for seamless in-place updates.
