# EasySwipe

EasySwipe is a lightweight native macOS menu bar utility for arranging windows with trackpad and Apple Magic Mouse gestures over a window's title bar.

The MVP supports three actions:

- swipe left to place the window on the left half of the current display;
- swipe right to place it on the right half;
- swipe down to minimize the window.

The product and technical requirements are documented in [docs/MVP-SPEC.md](docs/MVP-SPEC.md).
